CARA UPLOAD KE GITHUB

1. Extract ZIP ini.
2. Buka repository GitHub website kamu.
3. Upload isi folder hasil extract:
   - index.html
   - folder assets
4. Pastikan index.html berada langsung di root repository, bukan di dalam folder lain.
5. Klik Commit changes.
6. Tunggu GitHub Pages update, lalu tekan Ctrl + F5 di browser.
