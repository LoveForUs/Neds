CARA UPLOAD KE GITHUB

1. Extract file ZIP ini.
2. Upload index.html dan folder assets ke repository GitHub kamu.
3. Pastikan index.html berada langsung di root repository, bukan masuk folder lain.
4. Klik Commit changes.
5. Tunggu GitHub Pages update.
6. Buka website lalu tekan Ctrl + F5.
